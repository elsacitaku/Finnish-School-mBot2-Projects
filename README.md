# Finnish-School-mBot2-Projects
## Programming activities 
1. **Display my first name.** When the program starts, it shows my first name on the mBot2 screen.
2. **Display my surname and grade.** The program shows my surname on one line and *Grade 11* on the next line.
3. **Clear the screen.** The program removes the text from the mBot2 screen so it is ready to show a new message.
4. **Change the font size.** The program makes the text on the mBot2 screen bigger so it is easier to read.
5. **Change the RGB LED colors.** The program changes the lights in this order, with a one-second pause between colors.
- Red
- Green
- Blue
